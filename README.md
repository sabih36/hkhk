# Maria's Birthday Surprise Website 💗

## Files
- `index.html` — page structure and birthday message
- `style.css` — responsive pastel design and animations
- `script.js` — gift reveal, confetti, and synthesized birthday melody
- `birthday-scene.png` — optional generated artwork (included if available)

## Run it on your computer
1. Extract `maria_birthday_website.zip`.
2. Open the extracted folder.
3. Double-click `index.html`. It should open in your browser.
4. Click **Open Gift** to reveal the message.
5. Click **Play birthday music** if the melody is not already playing. Browsers require a click before playing audio.

## Publish it as a website link
### Option A: Netlify Drop
1. Open `https://app.netlify.com/drop` in your browser and sign in if asked.
2. Drag the extracted `maria_birthday_website` folder onto the upload area.
3. Wait for deployment and copy the public website URL Netlify gives you.
4. Send that link to Maria.

### Option B: GitHub Pages
1. Create a new public repository on GitHub.
2. Upload `index.html`, `style.css`, and `script.js` (and `birthday-scene.png` if included).
3. Open the repository's **Settings → Pages**.
4. Choose deployment from the `main` branch and root folder, then save.
5. Use the published URL shown by GitHub Pages.

## Personalize it
- Edit the message in `index.html` inside the `message-body` section.
- Change the sender name in the signature section.
- Change colors, fonts, and layout in `style.css`.
- The music is synthesized by `script.js`, so it works without a separate music file.

The website is static and does not collect or send anyone's personal information.
